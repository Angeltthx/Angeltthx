## 🚀 Featured Projects

### 🔹 Payroll Management System

A complete payroll management solution developed as an academic software project, focused on employee management, contracts, settlements, and business rules.

The project implements database logic and automated processes using **Oracle and PL/SQL**, demonstrating relational database design and backend business logic.

**Tech:** Java · Oracle · PL/SQL · SQL

---

### 🔹 DataBaseATC

Desktop application developed to manage and categorize pharmacological information using the **ATC classification system**.

The application includes data import, visualization, organization, and export functionality while working with large datasets.

**Tech:** Java · Swing · File Management

---

### 🔹 ZonaFitGYM

Full-stack gym management application implementing client management and CRUD operations through multiple interfaces.

The project combines backend development with web technologies and database integration.

**Tech:** Java · Spring Boot · JSF · PrimeFaces

---

### 🔹 EnergyDistributionAPI

Backend system designed to process, store, and analyze electric power distribution data.

The project focuses on database architecture, historical data processing, and exposing analytical information through an API.

**Tech:** C# · .NET · SQL · REST API

---

### 🔹 Territories Vivos

Web platform focused on presenting geographic and multimedia information through an interactive interface.

The project involved frontend development, interactive maps, multimedia integration, and working with large amounts of video content.

**Tech:** React · TypeScript · APIs · Interactive Maps · Vimeo
